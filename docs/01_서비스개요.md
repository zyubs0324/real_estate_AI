# 부동산 AI 어시스턴트 서비스 — 서비스 개요

## 서비스 목적

공인중개사가 복잡한 부동산 정책·법률·판례를 쉽게 조회하고, 특정 주소의 권리관계·규제 현황을 한눈에 파악하며, 일상 업무(거래 관리, 고객 이력, 기한 알림)를 효율적으로 처리할 수 있도록 돕는 AI 기반 내부 업무 도구.

## 서비스 대상

- 공인중개사 사무소 (대표 공인중개사, 소속 공인중개사, 중개보조원)
- 사무소 단위 내부 사용 (외부 공개 서비스 아님)

## 핵심 기능 2가지

### 기능 1 — 주소 기반 부동산 종합 진단 리포트

주소를 입력하면 해당 물건에 대한 규제·정책·권리관계·시세 정보를 구조화된 리포트로 즉시 제공.

**진단 항목:**
- A. 규제·정책 진단 — 토지거래허가구역, 투기과열지구, 조정대상지역, 재개발·재건축 구역, 용도지역, 공시지가
- B. 매물 진단 — 위반건축물, 주택유형·면적, 민간임대 등록 여부, 대지권, 가등기
- C. 권리관계 진단 — 근저당, 압류·가압류, 가처분, 경매, 신탁, 임차권등기명령, 전세권
- D. 시세 진단 — 실거래가, 보증금 적정성 판단
- E. 대출·보험 진단 — 전세보증보험 가입 가능 여부, 전세대출 한도 추정
- F. 범죄·치안 / 생활·편의 — 범죄 통계, 주변 편의시설
- G. 맞춤 특약 자동 생성 — 진단 결과 기반 AI 특약 문구

**리포트 한계 고지 (필수 표시):**
확정일자를 받은 선순위 임차인은 등기부에 표시되지 않아 리포트로 확인이 불가능합니다. 반드시 임대차 현황 확인서 또는 직접 확인을 권장합니다.

### 기능 2 — 부동산 특화 AI 질의응답

자연어로 복잡한 부동산 질문을 입력하면, 법령·판례·보도자료·고시 등 공공 데이터를 근거로 출처를 명시한 답변 제공. 특정 매물을 선택하면 해당 물건의 내부 CRM 데이터(거래 이력, 등록 인물, 메모)를 컨텍스트에 포함한 맞춤 답변 가능.

**예시 질문 유형:**
- 사실 조회: "서울시 신속통합기획 주택재개발사업 후보지 주소를 알고 싶어"
- 법령 해석: "6월 1일에 일시적 2주택이 됐다가 6월 2일에 1채 매도하면 종부세 나올까?"
- 복합 판단: "동생에게 아파트 매도 시 중개사인 내가 전자계약서를 작성해도 될까?"

**답변 원칙:**
- 출처 명시 (법령명 + 조항 + 판례번호)
- "이 답변은 법률 자문이 아닙니다" 고지
- 복잡한 사안은 세무사·변호사 상담 권고

## CRM 기능 (업무 관리 도구)

| 기능 | 설명 |
|---|---|
| 인물-주소 이력 관리 | 소유자·임대인·임차인 등 역할별 이력을 주소지와 연결해 추적 |
| 거래 정보 관리 | 매매·전세·월세 등 거래 등록, 참여자(다자간) 관리, 거래 상태 흐름 추적, 계약서 첨부 |
| 납부 단계 관리 | 계약금의계약금·계약금·중도금·잔금 단계별 금액·예정일·납부 완료 기록, 환불 처리 |
| 일정 관리 | 사전미팅·계약·잔금 일정 등록, 내부 구성원 + 외부 당사자(매도인·매수인) 참석자 지정 |
| 사전 고지 체크리스트 | 잔금 전 매도인·매수인·임대인·임차인에게 안내해야 할 항목 체크 및 고지 방법 기록 |
| 분쟁 이력 관리 | 계약파기·배액배상·보증금반환 분쟁 구조화 기록, 협의 타임라인, 증거 파일 첨부 |
| 기한 알림 | 부동산 거래 신고, 계약 만료, 갱신청구권 행사 기한 자동 알림 (이메일 + 문자) |
| 메모 기능 | 현장 정보를 주소·인물·거래·분쟁에 귀속 기록, 파일 첨부, 인물 주의(warning) 메모 |
| 빠른 확인 | 주소 입력만으로 위반건축물·등기 이상·규제지역 즉시 조회, 리스트 위험 태그 자동 표시 |
| 전체 매물 리스트 | 사무소 전체 매물을 위험 태그·필터·정렬로 조회, 리스트에서 위험 항목 즉시 확인 |
| 홈 대시보드 | 알림, 임박 계약, 최근 매물, 담당 거래 현황을 한 화면에 요약 |
| 사무소 권한 관리 | 구성원 역할(admin/member/assistant)별 접근 권한, 매물별 세부 권한 설정 |
| 타부동산 관리 | 협업·경쟁 부동산 중개사무소 정보 관리, 부동산중개업 API로 정보 자동 조회·채움 |
| 분쟁 이력 관리 (상세) | 계약파기·배액배상·보증금반환 분쟁 단계별 진행 현황, 협의 타임라인, 증거 첨부 |
| 사후관리·시설이력 | 입주 후 시설 하자·수리 이력 기록, 보증 기간 추적, AI 법률 조언 빠른 질의 연동 |
| 매물 사진 갤러리 | 매물별 사진 업로드·분류, 포트폴리오 뷰 |
| 외부 매물 수집 | 네이버부동산·직방 등 외부 플랫폼 URL에서 매물 정보 반자동 수집 |
| 구글 시트 동기화 | 기존 엑셀·구글 시트 매물 데이터 일괄 가져오기, 중복 감지 |
| DB 복구 기능 | 실수 삭제 데이터 30일 이내 복구 (Soft Delete 기반) |
| 데이터 수집 도구 | URL 즉시 크롤링, 직접 입력으로 AI 질의응답용 문서 색인 |

## 개발 방식

- 비개발자(공인중개사)가 Cursor + Claude Code 바이브 코딩으로 직접 구축
- Next.js (TypeScript) + Supabase + Vercel 스택으로 배포까지 완결
- **UI 디자인 시스템**: Apple 디자인 언어 기반 (`docs/apple.md` 공식 채택) — SF Pro → Pretendard(한국어), Apple System Colors, 글래스모피즘 사이드바, 슬라이드인 패널
- **소단위 육안 테스트 방식**: 각 기능을 1~3시간 단위(Unit)로 분해, 매 Unit마다 브라우저에서 눈으로 결과 확인 후 다음 Unit 진행
- **Mock 우선 개발**: API 키 없는 초기 단계에서는 `lib/apis/__mocks__/` Mock 데이터로 UI 먼저 완성, API 키 준비 후 실제 연동으로 전환
- **AI 모델**: GitHub Models (gpt-4o, Cohere-embed-v3-multilingual) — 무료, 별도 계약 불필요
