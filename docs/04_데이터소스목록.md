# 데이터 소스 목록 — API 키 발급 및 비용

## 공공 API (무료)

### 1. 도로명주소 API
- **용도:** 주소 표준화 레이어 — 도로명·지번 주소 입력을 표준 도로명주소 + 지번주소 + 좌표로 정규화
- **제공:** data.go.kr (행정안전부)
- **키 발급:** https://www.juso.go.kr/addrlink/devAddrLinkRequestGuide.do
- **비용:** 무료 (일일 한도 있음, 초과 시 증량 신청)
- **Phase:** 1 (모든 기능의 전제 조건)

### 2. 건축물대장 API
- **용도:** 위반건축물 여부, 주택유형·면적·층수, 민간임대주택 등록 여부
- **제공:** data.go.kr (국토교통부)
- **키 발급:** https://www.data.go.kr → 건축물대장 검색 → 활용신청
- **비용:** 무료
- **Phase:** 2

### 3. 실거래가 API
- **용도:** 아파트·연립·단독주택 실거래가 조회
- **제공:** data.go.kr (국토교통부)
- **키 발급:** https://www.data.go.kr → 국토교통부 실거래가 검색 → 활용신청
- **비용:** 무료
- **Phase:** 2

### 4. VWorld API
- **용도:** 토지이용계획 조회 (용도지역·지구·구역), 개별공시지가
- **제공:** 국토정보플랫폼 (공간정보 오픈플랫폼)
- **키 발급:** https://www.vworld.kr → 개발자 센터 → API 키 발급
- **비용:** 무료
- **Phase:** 2

### 5. 등기정보광장 Open API
- **용도:** 등기부 요약 정보 (근저당, 압류, 경매 등)
- **제공:** 대법원 등기정보광장 (data.iros.go.kr)
- **키 발급:** https://data.iros.go.kr → 오픈API 신청
- **비용:** 무료 (하루 1,000건 한도)
- **한계:** 요약 정보만 제공, 전문 파싱 불가
- **Phase:** 2

### 6. 법제처 법령·판례 API
- **용도:** 법령 원문 연동 (개정 시 자동 반영), 판례 배치 수집
- **제공:** 법제처 국가법령정보센터 (open.law.go.kr)
- **키 발급:** https://open.law.go.kr → OpenAPI 신청
- **비용:** 무료
- **Phase:** 4

### 7. 경찰청 공공데이터 API
- **용도:** 범죄 통계 (동 단위)
- **제공:** data.go.kr (경찰청)
- **키 발급:** https://www.data.go.kr → 경찰청 범죄 통계 검색 → 활용신청
- **비용:** 무료
- **Phase:** 2

### 8. 카카오맵 API
- **용도:** 주변 편의시설 (편의점, 학교, 병원, 지하철 등) 조회
- **제공:** 카카오 개발자센터
- **키 발급:** https://developers.kakao.com → 내 애플리케이션 → 앱 키 발급
- **비용:** 무료 (일 300,000건 한도, 초과 시 과금)
- **Phase:** 2

### 9. 부동산중개업 정보 서비스 API
- **용도:** 타부동산 자동 조회 — 상호명 또는 중개사무소 등록번호로 대표 공인중개사·주소·전화번호 일괄 조회
  - 타부동산 등록 시 상호명·등록번호 입력 → API 자동 조회 → 폼 자동 채움
  - 외부 수집 매물에 포함된 중개사 등록번호로 타부동산 자동 식별·연결
- **제공:** data.go.kr (국토교통부)
- **키 발급:** https://www.data.go.kr → "부동산 중개업 정보" 검색 → 활용신청
- **비용:** 무료
- **비고:** `DATA_GO_KR_API_KEY` 동일 키 사용 (별도 발급 불필요)
- **Phase:** 3-D-1 (타부동산 관리 구현 시)

## 민간 API (유료 or 제휴 필요)

### 10. CODEF API
- **용도:** 등기부 풀 파싱 (근저당·압류·가처분·신탁 등 전 항목)
- **제공:** 쿠콘 (developer.codef.io)
- **키 발급:** https://developer.codef.io → 회원가입 → API 신청
- **비용:** 건당 과금 (등기부 조회 1건당 약 50~100원 수준, 정확한 단가는 계약 시 협의)
- **특징:** 직방 지킴진단 등 대부분의 프롭테크 서비스가 이 방식 사용
- **Phase:** 2 (등기정보광장 API 한도 초과 또는 더 상세한 데이터 필요 시)

### 11. KB국민은행 시세 API
- **용도:** 현재 시세 (KB 시세)
- **제공:** KB국민은행
- **키 발급:** 제휴 계약 필요 (일반 개발자 신청 불가)
- **비용:** 제휴 계약 조건에 따라 결정
- **Phase:** Phase 5 이후 검토 (MVP에서는 실거래가로 대체)

## AI API

### 12. GitHub Models
- **용도:** AI 질의응답 답변 생성, 진단 리포트 종합 의견, 맞춤 특약 생성, 임베딩 생성
- **Base URL:** `https://models.inference.ai.azure.com`
- **키 발급:** GitHub → Settings → Developer settings → Personal access tokens (Fine-grained) → `models:read` 권한 선택
- **비용:** 무료 (GitHub Personal Access Token으로 즉시 사용, 별도 결제 없음)
- **SDK:** `openai` npm 패키지 (`baseURL` 오버라이드, OpenAI 호환 API)
- **사용 모델:**
  - `gpt-4o` — 한국어 법률 Q&A, 종합 의견 생성 (128K 컨텍스트)
  - `gpt-4o-mini` — 간단한 요약·분류
  - `Cohere-embed-v3-multilingual` — 한국어 법령 임베딩 (1024차원)
- **Phase:** 4 (U4-1부터 사용)

## 이메일·문자 서비스

### 13. Resend
- **용도:** 기한 알림 이메일 발송 (부동산 거래 신고 기한, 계약 만료, 갱신청구권), 일정 D-1 외부 당사자 이메일 알림
- **키 발급:** https://resend.com → 가입 → API Keys
- **비용:** 무료 플랜 3,000건/월, 유료 플랜 $20/월부터 (50,000건)
- **Phase:** 3 (거래 알림 기능 구현 시)

### 14. 솔라피(Solapi) — SMS 발송
- **용도:** 외부 당사자(매도인·매수인 등) 일정 알림 문자 발송
- **키 발급:** https://solapi.com → 회원가입 → API 키 발급
- **비용:** SMS 건당 약 8~11원, LMS(장문) 건당 약 27~30원
- **장점:** 카카오 알림톡 동일 플랫폼 지원 → 추후 카카오 확장 시 추가 연동 불필요
- **Phase:** 3 (일정 외부 알림 구현 시)

## API 키 관리 방법

모든 API 키는 `.env.local` 파일에 환경 변수로 저장. 절대 코드에 직접 삽입하지 않는다.

```env
# 주소 표준화
JUSO_API_KEY=

# 공공 데이터
DATA_GO_KR_API_KEY=
VWORLD_API_KEY=

# 등기부
IROS_API_KEY=
CODEF_CLIENT_ID=
CODEF_CLIENT_SECRET=

# AI (GitHub Models — 무료)
GITHUB_TOKEN=

# 지도
KAKAO_API_KEY=

# 이메일
RESEND_API_KEY=

# 문자(SMS)
SOLAPI_API_KEY=

# Supabase
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=

# 개발 환경 (API 키 없이 Mock 데이터로 개발 시 true, 실제 연동 시 제거)
NEXT_PUBLIC_USE_MOCK_API=
```

## 자체 DB 구축이 필요한 데이터

외부 API가 없어 직접 수집·관리해야 하는 데이터.

| 데이터 | 수집 방법 | 업데이트 |
|---|---|---|
| 토지거래허가구역 폴리곤 | 국토부·서울시 고시문 파싱 | 지정·해제 고시 시 수동 반영 |
| 투기과열지구·조정대상지역 행정구역 코드 | 국토부 고시 기반 | 지정·해제 고시 시 수동 반영 |
| 재개발·재건축 구역 | 서울시 도시계획포털 크롤링 | 일 1회 자동 or 수동 |
| 국토부 보도자료 | 국토교통부 홈페이지 크롤링 | 일 1회 자동 |
| 서울시 도시계획 고시 | 서울시 도시계획포털 크롤링 | 일 1회 자동 |
| 국세청 유권해석·예규 | 국세청 홈페이지 크롤링 | 주 1회 자동 |
| 공인중개사 관련 지침 | 직접 수집 | 수동 |
